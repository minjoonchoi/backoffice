# Backoffice MVP 이후 서버 기능 요구사항

## 1. 문서 정보

| 항목         | 내용                                                                           |
| ------------ | ------------------------------------------------------------------------------ |
| 문서 목적    | 현재 MVP UI에서 제외한 기능에만 필요한 서버 전용 규칙을 관리한다.              |
| 기준일       | 2026-08-16                                                                     |
| MVP 요구사항 | [Backoffice 서버 기능 요구사항](server-functional-requirements.md)             |
| UI 요구사항  | [Backoffice MVP 이후 UI 기능 요구사항](post-mvp-ui-functional-requirements.md) |

공용 데이터 무결성, 권한 계산, 알림 생성, 관계 변경 검증과 템플릿 규칙은 MVP 서버 기능 요구사항에 유지한다. 이 문서에는 제외된 UI를 다시 노출할 때 추가로 필요한 전용 query 또는 command만 둔다.

MVP 화면이 직접 노출하지 않더라도 현재 생성·조회·수정·삭제 흐름의 안전한 동작에 필요한 페이지네이션, 참조 무결성, 권한 검증, 트랜잭션, 멱등성과 감사 규칙은 후속으로 분류하지 않는다. `server-functional-requirements.md`에는 `후속` 상태를 두지 않으며, 이 문서로 이동할 수 있는 항목은 숨겨진 UI 전용 기능을 다시 활성화할 때만 필요한 서버 기능으로 제한한다.

## 2. 제외 범위

| 기존 ID    | 상태      | MVP 이후 기능                                                                                                                                                                                                                                 |
| ---------- | --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `HOM-S002` | 로컬 검증 | 알림 읽음 command는 알림 소유 사용자와 UI 기능 권한을 검증하고 읽음 시각을 저장해야 한다. 이미 읽은 알림에 대한 반복 command는 같은 결과를 반환해야 한다.                                                                                     |
| `POL-S016` | 로컬 검증 | 정책 충돌 분석은 Backoffice 시스템 관리자 권한을 검증한 뒤 유효 정책 중 같은 리소스의 허용·거부 정책을 반환해야 한다. 권한 시뮬레이션은 현재 사용자의 직접·조직·역할 정책과 가상 정책을 합산해 새 허용·기존 허용·거부 리소스를 구분해야 한다. |
