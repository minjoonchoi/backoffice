# 조직 메뉴 PRD

## 개요

- 목표: 계층 조직과 조직장, 사용자·역할·정책 및 소유 리소스 관계를 운영한다.
- routes: `/organizations`, `/organizations/new`, `/organizations/{organizationId}`, `/organizations/{organizationId}/edit`
- 주 사용자: IAM 운영자, 시스템 관리자
- 원본: UI `ORG-001~109`, 서버 `ORG-S001~005`, `IAM-S001~003`

## 제외 범위

조직장·사용자 집계, 조직 관계 변경 전용 집계와 고정 조직 요청 템플릿 역조회는 MVP 화면에서 제외한다(`ORG-106`, `ORG-110`).
