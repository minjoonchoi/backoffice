# 사용자 메뉴 PRD

## 개요

- 목표: 모든 사용자가 재직 중인 사용자 정보를 조회하고 IAM 권한 보유자가 다중 조직·역할 관계와 실효 정책을 운영한다.
- routes: `/users`, `/users/new`, `/users/{userId}`
- 주 사용자: 모든 재직·휴직 사용자, Access Governance IAM 운영자, Access Governance 시스템 관리자
- 원본: UI `USR-001~108`, 서버 `USR-S001~006`, `IAM-S001`, `IAM-S003`, `IAM-S006`

## 제외 범위

자격증명 이력, 요청 이력과 고정 사용자 결재 템플릿 참여 목록은 MVP 이후 범위다(`USR-105`, `USR-109`).
