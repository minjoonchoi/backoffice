# Backoffice MVP 이후 UI 기능 요구사항

## 1. 문서 정보

| 항목          | 내용                                                                                 |
| ------------- | ------------------------------------------------------------------------------------ |
| 문서 목적     | 구현 여부와 관계없이 현재 MVP 화면에서 제외하기로 확정한 UI 기능만 관리한다.         |
| 기준일        | 2026-08-16                                                                           |
| MVP 요구사항  | [Backoffice UI 기능 요구사항](ui-functional-requirements.md)                         |
| 서버 요구사항 | [Backoffice MVP 이후 서버 기능 요구사항](post-mvp-server-functional-requirements.md) |

이 문서의 기능은 현재 MVP의 메뉴, 페이지와 Dialog에서 진입점 또는 표시 영역을 제공하지 않는다. 이미 구현된 컴포넌트와 도메인 로직은 향후 재사용을 위해 유지할 수 있으며, 다시 MVP에 포함할 때 요구사항과 권한 리소스, 테스트를 함께 복원한다.
